This directory contains data for different use cases.

1. RL training: `grpo_data_level3.json`, which is the level3 data from MATH500 dataset.
2. PRM training: You can download our data from huggingface for TDRM training:
`https://huggingface.co/datasets/zd21/TDRM-1-step-TD` 
`https://huggingface.co/datasets/zd21/TDRM-2-step-TD` 
`https://huggingface.co/datasets/zd21/TDRM-3-step-TD` 
3. PRM evaluation: `mistral_rlhflow_bo128/output.json`, which contains Mistral responses of MATH500. 128 responses for each question.
